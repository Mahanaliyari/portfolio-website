# Personal Portfolio Website

A responsive, single-page portfolio that introduces me, my skills, projects and achievements. Built with plain HTML, CSS and JavaScript.

**Live site:** https://mahanaliyari.github.io/portfolio-website/

## About the project

This site brings together the work I'm proudest of in one place and gave me a chance to learn front-end fundamentals from scratch: semantic HTML, modern CSS layout and basic JavaScript interactivity.

## Features

- **Seven sections:** hero, about, skills, projects, achievements, contact and footer
- **Responsive layout:** works from small phones to wide desktop screens, using CSS Grid, Flexbox and a media query
- **Sticky navigation** with smooth scrolling to each section
- **Mobile menu:** the links collapse behind a toggle button on small screens
- **Light and dark theme:** a toggle switches themes, and the choice is remembered between visits using `localStorage`
- **Consistent design system:** all colours, spacing and radii are defined once as CSS variables
- **Accessibility basics:** semantic elements, visible keyboard focus styles, `aria` attributes on the menu button, and support for reduced-motion preferences

## Technologies

- HTML5
- CSS3 (custom properties, Grid, Flexbox, media queries)
- JavaScript (DOM manipulation, event listeners, `localStorage`)
- Git and GitHub
- GitHub Pages for hosting

## Running it locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Mahanaliyari/portfolio-website.git
   ```

2. Open the folder and double-click `index.html`, or use the Live Server extension in VS Code for automatic reloading.
